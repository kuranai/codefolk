# Changelog

All notable changes to Codefolk are documented here.

## [Unreleased]

## [0.1.4] - 2026-09-26

### Changed

- Removed dark theme, better readabillity

## [0.1.3] - 2026-07-22

### Changed

- Removed dashed hover outlines from toolbar actions and navigation tabs.

## [0.1.2] - 2026-07-22

### Changed

- Removed the global dashed focus outline from interactive workbench controls.

## [0.1.1] - 2026-07-22

### Changed

- Restored the characteristic editor palette, subdued workbench chrome, differentiated tabs, and classic Git status colors while retaining modern Codefolk workbench coverage.

## [0.1.0] - 2026-07-22

### Added

- Codefolk derived from the escook palette.
- Curated coverage for 553 VS Code 1.129.1 workbench color IDs.
- Semantic highlighting for declarations, types, functions, parameters, properties, readonly values, and deprecated symbols.
- Modern editor, terminal, notebook, SCM/merge, debug, testing, chat, and workbench colors.
- Deterministic TypeScript theme generator, registry validation, contrast checks, visual fixtures, VSIX packaging, and release automation.

### Changed

- Restored escook's characteristic editor palette for strings, keywords, constants, functions, parameters, types, and comments while retaining modern Codefolk workbench coverage.
- Restored escook's stronger active Activity Bar item, quieter SCM section headers and inactive tabs, and classic VS Code Git status colors.
